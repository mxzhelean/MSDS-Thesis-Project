K-Nearest Neighbors (KNN) is one of the most intuitive supervised machine
learning algorithms in data science, capable of solving both classification and
regression problems. Unlike models that learn explicit equations during
training, KNN is a non-parametric, "lazy" (instance-based) learner. Rather than
building an abstract model beforehand, KNN simply memorizes the training dataset
and defers all heavy computation until it is asked to make a prediction.

The algorithm rests on a simple geometric intuition: similar data points tend to
live near one another. If we represent each observation as a point in a
multi-dimensional coordinate system (called feature space), we can predict an
unknown point’s outcome by examining the known outcomes of its closest
neighbors.

When given a new, unlabeled data point, KNN follows four steps:

1.  Choose K: Select the number of neighbors (K) to consult, such as 3, 5, or 7.
2.  Calculate Distance: Measure the distance between the new point and every
    point in the training dataset. Most commonly, KNN uses Euclidean distance
    (straight-line distance), though alternatives like Manhattan distance exist.
3.  Find the Nearest Neighbors: Rank all training points from closest to
    farthest and select the top K neighbors.
4.  Aggregate to Predict:
      - In classification, KNN takes a majority vote among the K neighbors,
        assigning the most common class label.
      - In regression, KNN computes the mean (or median) of the K neighbors’
        numerical target values.

For example, imagine predicting whether a house is "High-Priced" or "Budget"
using its square footage and distance from downtown. Plotting past sales on a 2D
graph with K=5, KNN finds the five closest historical homes to a new listing. If
four are "High-Priced" and one is "Budget," KNN predicts "High-Priced."

Using KNN effectively requires attention to two critical details. First, feature
scaling is mandatory. Because KNN relies entirely on distance, a variable
measured in large numbers (like square footage in the thousands) will
mathematically overwhelm a variable measured in small numbers (like number of
bedrooms) unless features are normalized to a similar scale. Second, selecting K
involves balancing overfitting and underfitting. A tiny K (such as K=1) makes
predictions overly sensitive to random noise and outliers, whereas a very large
K can blur distinct boundaries between groups. Choosing an odd K is also
standard practice in binary classification to avoid tie votes.

Overall, KNN is prized as a strong baseline model because it is easy to
interpret and adapts naturally to complex data shapes without assuming any
underlying distribution. Its main drawback is computational efficiency: on
massive datasets, comparing every new query against millions of stored records
becomes slow at prediction time.
